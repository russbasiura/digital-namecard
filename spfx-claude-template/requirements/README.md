# Requirements inputs

Put the project inputs here and commit them:

- `*.xlsx` — the Business Requirements Document (any column layout; multiple sheets/files OK)
- `design/` — the application design package: screenshots/mockups (`.png`, `.jpg`), PDFs, style guides, notes.
  Name screenshots meaningfully, e.g. `01-home-desktop.png`, `01-home-mobile.png`, `02-detail-quickview.png`.

Generated by Claude (don't edit by hand unless correcting):
- `requirements.json` — normalized requirements (`/ingest`)
- `design/_from-brd/` — images extracted from the BRD workbook

Edit freely:
- `status.json` — mark requirements `deferred` / `out-of-scope` with a reason
